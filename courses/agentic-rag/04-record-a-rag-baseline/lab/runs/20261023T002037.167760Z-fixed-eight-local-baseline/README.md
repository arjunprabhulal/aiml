# One saved local RAG baseline

This directory contains one actual local recording over the frozen eight teaching cases. `recording.json` holds original per-query timing; `automatic-contracts.json` holds replay grading timing. They are different measurements. `http-ledger.json` preserves every actual request and NDJSON response; no credentials or request headers were recorded.

The frozen source bundle is `f1d5776e582b503c87e8842f9c650e5c175a4106931069ef7bc9813849aa8e6c`. Do not edit the 27 files outside `runs/`: replay checks their exact hashes. The top-level preparation README is deliberately retained as the original preflight document; this dated directory records what happened afterward.

`human-review.json` is unreviewed. `assistant-review.json` is an AI answer inspection, not an owner verdict or independent approval. There are no repaired model responses. One case has empty final content and a length stop; its parse error remains part of the recording.

The output images are genuine 2× browser captures of a saved-result summary generated by `render_report.py`; they are not terminal screenshots or a new model run. The compact summary selects three diagnostic cases and omits the other five answers, intermediate events, environment details and wire chunks. Follow the raw JSON links for those complete records. Generated report HTML stays outside the site source.

To reproduce the display without inference:

```sh
python runs/20261023T002037.167760Z-fixed-eight-local-baseline/render_report.py --html /tmp/rag-baseline-output/report.html
python runs/20261023T002037.167760Z-fixed-eight-local-baseline/test_saved_run.py
```

To re-evaluate the saved responses without a new model call, from the lab root:

```sh
python baseline.py replay --record runs/20261023T002037.167760Z-fixed-eight-local-baseline
```

Fresh inference is a separate explicit operation. Do not rerun it to improve these saved results.
