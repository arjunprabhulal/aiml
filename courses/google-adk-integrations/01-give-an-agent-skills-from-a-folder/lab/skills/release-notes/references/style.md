# Release notes style

- Start with `## docuctl <version>`.
- Sections, in this order, only when they have entries: **Breaking changes**, **Features**, **Fixes**, **Docs**.
- One bullet per pull request: the title without its `type:` prefix, then the number in parentheses, e.g. `- Add --dry-run to rollback (#212)`.
- Put a `!` type (such as `feat!:`) under Breaking changes.
- Leave out `chore` and `ci` pull requests.
