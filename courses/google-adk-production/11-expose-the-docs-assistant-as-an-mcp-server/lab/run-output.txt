# connection 1
> I'm on docuctl 1.x. How do I roll back production to r41?
answer In docuctl 1.x, use:

```bash
docuctl release revert r41
```

(In docuctl 2.x, this was replaced by `docuctl rollback --env production --to r41`.)  (9.3s)
> And how do I list the releases of production?
answer In docuctl 1.x, use:

```bash
docuctl release list --env production
```

(In docuctl 2.x, this was replaced by `docuctl releases --env production`.)  (5.7s)

# connection 2
> And how do I list the releases of production?
answer To list the releases for the production environment, run:

```bash
docuctl releases --env production
```

This lists the releases newest first, along with their status (`live`, `previous`, `degraded`, `failed`, or `pending`).  (3.2s)
