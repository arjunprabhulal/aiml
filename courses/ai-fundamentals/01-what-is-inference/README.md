[![Run inference with a local LLM](lesson.png)](https://aiml.sh/courses/ai-fundamentals/what-is-inference/)

Run a language model with and without supplied documentation, and explain how request context differs from trained model weights.

- **Reading time:** 9 min
- **Uses:** ollama 0.6.3 (Python client), pytest 9.1.1, the gemma4:e2b model

## Lab

The [`lab/`](lab/) folder holds the complete runnable code, tests and recorded outputs, the same files as the lesson's download on aiml.sh. The lesson explains each step.

### Lab notes

#### Run inference with a local LLM

Download `/labs/what-is-inference.zip` and extract it. Keep the included fixtures and Python files together in `what-is-inference/`. Requires Python 3.12 or later.

##### Setup, tests and execution

From this directory:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt

#### Offline tests: no model calls
.venv/bin/python -m pytest -q

#### Run after reading the implementation below
ollama pull gemma4:e2b
.venv/bin/python inference.py
```

The live commands contact Ollama or the hosted provider; the offline tests replace model calls. Run them from the extracted lab directory. Saved outputs describe earlier runs and are not regenerated by the offline tests.

Read `inference.py` before its live run. Some drivers write their results next to the source; use a fresh extracted copy when comparing with the bundled recordings. The tests exercise the implementation with local fixtures or replaced model clients; passing them does not establish model quality.
